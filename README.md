# Construction Animation

Construction Animation is a code mod for Cities: Skylines II that makes building construction visibly progress over time.

Instead of hiding a finished building under the vanilla construction surface, buildings rise progressively using their native models and textures.

## Features

- Progressive building construction
- Native façades and window materials
- Procedural scaffolding that follows the building footprint
- Scaffolding shadows and animated dismantling
- Tower cranes on suitable construction sites
- Temporary dirt construction ground
- Concrete foundation during construction
- Smooth transition between the animated construction and completed building
- Support for multiple simultaneous construction sites
- Performance optimizations for large buildings and multiple projects

## Requirements

- Cities: Skylines II 1.6.x
- No additional dependencies

## Status

The mod is currently in beta. Some unusual building footprints may still produce visual imperfections.
